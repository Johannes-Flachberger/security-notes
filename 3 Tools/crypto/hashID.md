# Info

Identifies the type/algorithm of a given hash.

might not always be 100% accurate

**Alternative Tool:** [hash-identifier](https://www.kali.org/tools/hash-identifier/)

info about hash types: [https://hashcat.net/wiki/doku.php?id=example_hashes](https://hashcat.net/wiki/doku.php?id=example_hashes)

# Usage

Example: `hashid <hash>`

if the hash contains hashing special character, put it in single quotes (`'`)
