# Info

Identifies technologies used on websites

- passive & active
- browser extension that analyses websites, used frameworks,.. (active)
- also has a searchable register of sites & their technologies (passive)
	- <https://www.wappalyzer.com/lookup/>
- reveals the whole technology stack: OS, UI frameworks, webservers, databases, javascript libraries,...
- There also is a paid pro version

# Usage

install browser extension & browse to website
