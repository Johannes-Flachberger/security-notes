# Info
nice tool to copy webpages
# Usage
``` bash
httrack <URL> -O <output-directory>
```
## Essential Options

| Option | Purpose |
|----------|--------------|
| `-O <dir>` | Output directory |
| `-rN` | Recursion depth |
| `-cN` | Number of connections |
| `-n` | Get images and media |
| `-i` | Continue interrupted download |
| `-v` | Verbose output |
| `+<filter>` / `-<filter>` | Include/exclude URL patterns |
