alternative tool: `host` command in kali

# Usage

`dig [@SERVER] <DOMAIN_NAME> <TYPE>`

| Option        | Command                  |
| ------------- | ------------------------ |
| `TYPE`        | DNS record type to quers |
| `DOMAIN_NAME` | domain                   |
| `SERVER`      | DNS server to use        |
