# Pentesting

## Discovery

While implementation of techniques is specific to a cloud service, the overarching workflow and techniques are similar for all cloud services.

**Starting point:** Initial compromise of a cloud environment, e.g. by obtaining an access key.

**Worklow:**
1. Examine the obtained credentials
	- Which account & entity (e.g. user) do they belong to?
2. Enumerate Permissions of the obtained entity
	- Permissions
	- Group memberships & the groups permissions
3. Enumerate further resources accessible to the entity
