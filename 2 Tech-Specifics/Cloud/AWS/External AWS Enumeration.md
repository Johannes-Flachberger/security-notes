# Fundamentals

When performing reconnaissance on cloud systems, the starting point is usally the domain name.

# Pentesting

- Perform [[1 Methods/Security-Testing/1 Reconnaissance/Passive Recon/Overview - Passive Recon|Generic Passive Recon]]
- DNS Enum: see [[2 Tech-Specifics/Network/Protocols/TCP,UDP 53 DNS#Enumeration|DNS]]
	- perform reverse lookups of discovered IPs to identify the service-specific domain name - this most often reveals the type of the used AWS resource
