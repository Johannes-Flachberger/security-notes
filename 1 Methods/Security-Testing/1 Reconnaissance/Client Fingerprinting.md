# Tracking tokens
A tracking token is sent to the target which extracts and stores information about the targets browser, OS, etc.

Tracking tokens can be embedded in numerous technologies, such as
- links
- office documents
- pdfs
- windows folders

Tools:
- https://canarytokens.com/nest/ (most feature rich)
- https://grabify.link/ (ip logger)
- include [fingerprint.js](https://github.com/fingerprintjs/fingerprintjs) in a webpage and serve it to the target
